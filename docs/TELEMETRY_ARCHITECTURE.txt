# Telemetry System Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                         Java Application                         │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │                    TelemetryPanel (JavaFX)                │   │
│  │  • Real-time graphs (FPS, frame time)                     │   │
│  │  • Pass breakdown chart                                   │   │
│  │  • Ring buffer visualization                              │   │
│  └──────────────────────────────────────────────────────────┘   │
│                              │                                    │
│                    ┌─────────▼─────────┐                         │
│                    │   FFM Bindings     │                         │
│                    │  (auto-generated)  │                         │
│                    └─────────┬─────────┘                         │
└──────────────────────────────┼──────────────────────────────────┘
                               │ C ABI
                     ┌─────────▼─────────┐
                     │   EngineAPI.h      │
                     │  (C FFM Interface) │
                     └─────────┬─────────┘
                               │
┌──────────────────────────────▼──────────────────────────────────┐
│                     C++ Engine (Native)                          │
│                                                                   │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                    EngineContext                           │  │
│  │  • Owns Telemetry instance                                │  │
│  │  • Integrates into frame lifecycle                        │  │
│  │  • Provides accessor methods                              │  │
│  └───────────────────┬────────────────────────────────────────┘ │
│                      │                                            │
│  ┌───────────────────▼────────────────────────────────────────┐ │
│  │                    Telemetry                               │ │
│  │  ┌──────────────────────────────────────────────────────┐ │ │
│  │  │ Current Frame Stats                                  │ │ │
│  │  │  • Frame number, CPU/GPU time                        │ │ │
│  │  │  • Draw calls, triangle count                        │ │ │
│  │  │  • Pass count                                        │ │ │
│  │  └──────────────────────────────────────────────────────┘ │ │
│  │  ┌──────────────────────────────────────────────────────┐ │ │
│  │  │ Ring Buffer (300 frames)                             │ │ │
│  │  │  [Frame 0] [Frame 1] ... [Frame 299]                 │ │ │
│  │  │  └─ head pointer (circular wrap-around)              │ │ │
│  │  └──────────────────────────────────────────────────────┘ │ │
│  │  ┌──────────────────────────────────────────────────────┐ │ │
│  │  │ Pass Timings (16 max)                                │ │ │
│  │  │  [Clear] [Grid] [Axes] [PointSprite] ...             │ │ │
│  │  │  └─ name + duration_ms for each pass                 │ │ │
│  │  └──────────────────────────────────────────────────────┘ │ │
│  └─────────────┬──────────────────────────────────────────────┘ │
│                │                                                  │
│  ┌─────────────▼────────────────────────────────────────────┐   │
│  │                    RenderGraph                           │   │
│  │  • Executes render passes                                │   │
│  │  • Per-pass timing via begin_pass/end_pass               │   │
│  │  ┌────────────────────────────────────────────────────┐ │   │
│  │  │ for each pass:                                     │ │   │
│  │  │   if (telemetry enabled):                          │ │   │
│  │  │     idx = telemetry->begin_pass(pass->get_name())  │ │   │
│  │  │     pass->execute(...)                             │ │   │
│  │  │     telemetry->end_pass(idx)                       │ │   │
│  │  └────────────────────────────────────────────────────┘ │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                   │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │                    RenderPasses                          │   │
│  │  • ClearPass, GridPass, AxesPass, etc.                   │   │
│  │  • Each implements get_name() for telemetry              │   │
│  └──────────────────────────────────────────────────────────┘   │
└───────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════
                         DATA FLOW
═══════════════════════════════════════════════════════════════════

Frame Timing:
  EngineContext::begin_frame()
    └─> telemetry->begin_frame(frame_number)
        └─> Records start time

  EngineContext::end_frame()
    └─> telemetry->end_frame(draw_calls, triangles)
        └─> Computes CPU time
        └─> Stores in ring buffer

Pass Timing:
  RenderGraph::execute()
    └─> for each pass:
          if (telemetry enabled):
            idx = telemetry->begin_pass(name)
            pass->execute()
            telemetry->end_pass(idx)
          // Note: Manual timing used to avoid header dependencies
          //       (PassTimer RAII is available for other use cases)

Retrieval (from Java):
  astraeus_get_telemetry_frame_stats()
    └─> EngineContext::get_telemetry_stats()
        └─> Telemetry::get_current_stats()
            └─> Returns current frame stats

  astraeus_get_telemetry_history()
    └─> EngineContext::get_telemetry_history()
        └─> Telemetry::get_history()
            └─> Copies ring buffer to output

  astraeus_get_pass_timing()
    └─> EngineContext::get_telemetry_pass_timing()
        └─> Telemetry::get_pass_timing()
            └─> Returns pass name + duration

═══════════════════════════════════════════════════════════════════
                        PERFORMANCE
═══════════════════════════════════════════════════════════════════

Overhead when ENABLED:
  • Per-frame:  ~500-1000 ns (chrono + ring buffer write)
  • Per-pass:   ~10-50 ns (RAII timer + chrono)
  • Memory:     ~50 KB (300 frames + 16 passes)
  • Total:      ≤ 1-2% of frame time

Overhead when DISABLED:
  • ZERO - All calls become inline no-ops
  • Compiler optimizes away all telemetry code

Memory Layout (cache-friendly):
  • FrameStats: 40 bytes (aligned)
  • PassTiming: 48 bytes (aligned)
  • Ring buffer: Sequential array (good locality)
```
