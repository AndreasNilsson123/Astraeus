1. User clicks ImageView at scene coordinates (e.g., 640, 360)

2. FxViewport transforms coordinates:
   • scaleX = currentWidth / imageView.fitWidth
   • scaleY = currentHeight / imageView.fitHeight
   • viewportX = (int)(sceneX * scaleX)  → e.g., 640
   • viewportY = (int)(sceneY * scaleY)  → e.g., 360

3. NativeEngine.pick(640, 360) invoked

4. FFM MethodHandle calls astraeus_pick(engine, 640, 360)

5. C++ reads ID buffer at pixel (640, 360):
   • entityId = idBuffer[360 * width + 640]  → e.g., 42
   • depth = depthBuffer[360 * width + 640]  → e.g., 0.756
   • worldPos = unproject(640, 360, 0.756, camera)  → e.g., (1.2, 3.4, 5.6)

6. PickResult struct returned by value (24 bytes on stack)

7. PickingView created from MemorySegment, values copied to Java

8. Callback invoked: onEntitySelected.accept(pickingView)

9. UI updates:
   • FxViewport: Show yellow selection overlay at click position
   • SceneInspector: Display entity ID, position, depth
