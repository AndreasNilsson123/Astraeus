┌──────────────────────────────────────────────────────────────────────────────┐
│  TYPICAL WORKFLOW                                                            │
└──────────────────────────────────────────────────────────────────────────────┘

1. Launch Application
   mvn javafx:run -Djavafx.mainClass=com.astraeus.test.TelemetryDemoApp

2. Quick Performance Check
   - Telemetry overlay is visible by default
   - Glance at FPS and frame time while working
   - Press F3 to hide when not needed

3. Detailed Performance Analysis
   - Press T to open telemetry panel
   - Review per-pass breakdown
   - Identify bottleneck passes (highest %)
   - Sort table by clicking column headers

4. Optimize and Compare
   - Make changes to engine/scene
   - Watch FPS in real-time
   - Compare pass timings before/after

5. Disable When Not Needed
   - Press E to disable telemetry collection
   - Reduces overhead to 0%
   - Re-enable when profiling needed

┌──────────────────────────────────────────────────────────────────────────────┐
│  INTEGRATION PATTERNS                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

Pattern 1: Overlay Only (Minimal)
────────────────────────────────────
StackPane container = new StackPane();
container.getChildren().addAll(viewport, telemetryOverlay);
StackPane.setAlignment(telemetryOverlay, Pos.TOP_LEFT);


Pattern 2: Panel Only (Detailed)
────────────────────────────────────
TelemetryPane pane = new TelemetryPane(engine);
TabPane tabs = new TabPane();
tabs.getTabs().add(new Tab("Telemetry", pane));


Pattern 3: Both (Complete)
────────────────────────────────────
// Overlay in viewport
StackPane container = new StackPane();
container.getChildren().addAll(viewport, telemetryOverlay);

// Panel in side tab
TabPane tabs = new TabPane();
tabs.getTabs().add(new Tab("Telemetry", pane));

// Keyboard shortcuts
scene.addEventHandler(KeyEvent.KEY_PRESSED, e -> {
    if (e.getCode() == KeyCode.F3) {
        telemetryOverlay.setVisible(!telemetryOverlay.isVisible());
    }
});

Render Loop (60+ FPS)          Telemetry Update (30 Hz)
─────────────────────          ────────────────────────

      ┌─────────┐                    ┌──────────┐
      │ Frame 1 │                    │ Update 1 │

           │                              │

      │ Frame 2 │                         │

           │                              │
      ┌────▼────┐         ┌───────────────▼────────────┐
      │ Frame 3 │────────▶│  Read frame stats          │
      └────┬────┘         │  Update overlay            │
           │              │  Update pane               │
      ┌────▼────┐         └────────────────────────────┘
      │ Frame 4 │
      └────┬────┘                    ┌──────────┐
           │                         │ Update 2 │
      ┌────▼────┐                    └────┬─────┘
      │ Frame 5 │                         │
      └────┬────┘                         │
           │                              │
      ┌────▼────┐         ┌───────────────▼────────────┐
      │ Frame 6 │────────▶│  Read frame stats          │
      └─────────┘         │  Update overlay            │
                          │  Update pane               │
                          └────────────────────────────┘

Benefits:
• Reduces UI churn (no flicker)
• Minimizes CPU overhead
• Smooth, readable display
• Configurable rate (adjust TELEMETRY_UPDATE_INTERVAL_NS)
